どう作っているか（リーン・アジャイル）

  1. 北極星指標を1つ決める（週に記録した人の数）。売上ではなく、ユーザーが価値を受け取った数
  2. 仮説は「判定日」と「計器」が書けるものだけ。1つの版で確かめる思い込みは1つ
  3. 作る前にフェイクドア（ボタンだけ置いて押した人の割合を数える）
  4. 公開から7〜14日で判定し、効いた／効かない／判定不能のどれかを必ず書く
  5. 結果を学びの台帳に「仮説→やったこと→結果→解釈→次」で残し、原則に抜き出す
  6. 使われない機能は消す。機能は出したあとまで面倒を見る

大きな判断と失敗

  • 11/2 週次: ボトルネックは検索からの新規。名前とキーワードは 11/7 の判定まで触らない
  • 11/1 月次棚卸し。置かれないウィジェットと、届かない募集カードを次の版で外す
  • 10/31 買う人は最初の数日で過去をまとめて書く。その入力を楽にする版を先に出す。広告はまだ出さない
  • 10/30 名前から「支出」を戻しても流入は戻らなかった。消えていたのは「手帳」と「記録」
  • 10/26 計画を作り直し。先に課金と残存、次に年末、広告は1インストールの価値が単価を超えてから。目標日 2027-06-30
  • 9/28 検索広告を停止。1インストール約¥360、売上見込み約¥55で6倍の赤字
  • 10/1 全データの書き出し・復元を無料に（記録はその人のもの）
  • 10/4 訂正: 有料を3人と数えていた（本当は7人）。集計のバグ
  • 10/7 ミッション・北極星指標・主ペルソナを決めた。顔は「推してきた記録の振り返り」
  • 10/9 X の投稿より検索（新規の95%）を直すべきだった
  • 11/7 今の仕組みの天井は有料 約24人と分かり、入る人数・買う率・残る率を同時に動かす計画に作り直した
  • 11/8 他のアプリのオンボーディングと課金を4方向で調べた。課金画面を「困りごと → 解ける」に書き直し、解約の画面には割引なしで「記録は残る」とだけ伝えることにした
